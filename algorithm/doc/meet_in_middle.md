# Meet in Middle 

어떤 수열에서 부분 합이 특정 수 이하의 개수를 구할 때 쓰는 알고리즘입니다.

`brute force`를 통해 구할 수 있지만, 최악의 경우 시간복잡도: $O(2^n * n)$를 
기록합니다.

**Pseudo Code**:
- set: [1, 2, 3]

## brute force

```py
def brute_force(sample: list) -> list[list]:
    full_set: list[list] = [];
    n: int =  len(sample);

    # 총 2^n 걸리므로 비트 연산자를 통해 2^n를 구합니다.
    for i in range(0, 1 << n):
        subset: list = [];

        for j in range(0, n):
            if i & (1 << j):
                subset.append(sample[j]);

        full_set.append(subset);

    return full_set;
```

`bit` 특성을 사용합니다.

- 0000 0000
- 0000 0001
- 0000 0010
- 0000 0011
- 0000 0100
- 0000 0101
- 0000 0110
- 0000 0111

보시는 바와 같이 비트는 1이 증감할 수록 멱 집합과 비슷한 패턴을 가집니다.

`brute force` 특성상 모든 경우의 수를 탐색합니다. 최대 범위는 2^n - 1 까지이므로
첫 번째 루프에는 0부터 2^n까지 실행합니다.

두 번째 루프에서는 0부터 n까지 수행합니다.

- 두 번째 루프의 값의 `bit`가 첫 번째 루프의 `bit`값의 포함 될 경우, 두 번째
값의 위치하는 원소를 부분 집합의 넣습니다. 
    - 첫 번째 수 3: 0111
    - 두 번째 수 2: 0010
    - 따라서 부분 집합의 위치 2의 해당하는 원소를 넣습니다.
    
두 번째 루프가 끝나면 멱집합의 추가합니다.

## dfs

1. 1을 방문합니다.
    - 현재 집합: {1},
    - 1이 들어간 집합을 다음 원소에 넘깁니다.
    1. 2를 방문합니다.
        - 1이 들어간 집합을 받습니다. 그 안에 2를 넣습니다.
        - 현재 집합: {1}, {1, 2}
        - {1, 2}가 들어간 집합을 다음 원소에 넘깁니다.
        - 돌려줄 집합: {1, 2}
        1. 3을 방문합니다.
            - {1, 2}가 들어간 집합을 받습니다. 그 안에 3을 넣습니다.
            - 현재 집합: {1}, {1, 2}, {1, 2, 3}
            - 다음 원소가 없으므로 돌아갑니다. 백트랙킹 합니다.

    2. 3을 방문합니다.
        - 1이 들어간 집합을 받습니다.
        - 집합 안에 3을 넣습니다.
        - 현재 집합: {1}, {1, 2}, {1, 2, 3}, {1, 3} 
        - 다음 원소가 없으므로 돌아갑니다. 
2. 2를 방문합니다.
    - 현재 집합: {1}, {1, 2}, {1, 2, 3}, {1, 3}, {2}
    - 2가 들어간 집합을 다음 원소에 넘깁니다.
    1. 3을 방문합니다.
        - 2가 들어간 집합에 3을 넣습니다.
        - 현재 집합: {1}, {1, 2}, {1, 2, 3}, {1, 3}, {2}, {2, 3}    
        - 마지막 원소이므로 돌아갑니다.

3. 3을 방문합니다.
    - 현재 집합: {1}, {1, 2}, {1, 2, 3}, {1, 3}, {2}, {2, 3}, {3}
    - 마지막 원소이므로 돌아갈 곳이.. 없습니다.
    종료합니다.

위와 같이 재귀적, `dfs`, `backtracking`을 통해 구할 수 있습니다.
`dfs`는 시간 복잡도가 $O(2^n)$

brute force 보다는 빠릅니다. 다만, N이 커질수록 지수적으로 증가하기 때문에,
큰 N은 둘다 느립니다.

```py
def get_power_set(sample: list, idx: int, subset: list) -> list:
    full_set: list = [];
    full_set.append(subset);

    for i in range(idx, len(sample)):
        full_set.extend(get_power_set(sample, i + 1, subset + [sample[i]]));

    return full_set;
```
