# 💳 문제이해

1 ~ N 개의 구성된 이진 나무가 있습니다. `inorder`와 `postorder traverse`의 출력 결과가
주어졌을 때, `preorder traverse`의 과정을 구하시오.

# 🚥 문제접근

둘 중 하나만 주어져도, `preorder traverse`를 구할 수 있을 거라 생각했는데,
두 개식이나 주어진 것을 보면 `preorder traverse`를 구하기 위해서는 
두 개의 순회 방식의 과정이 필요하다고 가정합니다.

## 🌏 분석

- 중위 순회: 1, 2, 3, 4, 5
- 후위 순회: 1, 3, 2, 5, 4

중의 순회만 주어졌을 어떤 번호가 루트인지 모르겠습니다.
하지만 후위 순회의 경우 마지막 번호가 루트 노드 입니다.

하지만, 루트를 알고 있음에도 나올 수 있는 경우가 두 가지입니다.

1. 1, 3의 부모 노드가 2인 경우
2. 2의 부모가 3이면서 3의 부모 노드가 루트인 경우

이 때 후위 순회를 통해 부모 노드의 오른쪽 노드를 확인할 수 있습니다.

1. 1, 3이기 때문에 첫 번째가 정답입니다. 이는 오른쪽 노드가 3인 것을 의미합니다.
    - 후위 순회인 경우 특성상 바로 옆에 있는 번호는 부모가 될 수 없습니다.

따라서 전위 순회의 과정은
- 4, 2, 1, 3, 5

여기서 알 수 있는 점은 루트 노드와, 루트 노드의 왼쪽, 오른쪽 
부분 트리입니다. 

- 루트 노드: 후위 순회의 과정 마지막 노드
- 루트의 왼쪽, 오른쪽 부분 트리: 중위 순회 과정에서 루트 기준 
왼쪽은 왼쪽 부분 트리, 오른쪽은 오른쪽 부분 트리

전위 순회는 루트, 왼쪽, 오른쪽 노드 순입니다.
루트를 구한 다음에 나누어진 왼쪽, 오른쪽 부분 트리에 위 과정을
반복하면 될 것 같습니다.

### 🛠️ 풀이

1. 후위 순회에서 루트 번호를 구합니다.
2. 중위 순회에서 루트를 기준으로 왼쪽, 오른쪽을 구간을 나눕니다.
3. 후위 순회는 중의 순회에서 나눈 왼쪽 오른쪽 구간에 길이에 따라 나눕니다.
4. 위 과정을 탐색을 다 할 때까지 반복합니다.(모든 부분 트리가 0개 미만일 때)

#### 🖥️ source code

```cpp
#include<iostream>
#include<vector>

using namespace std;
typedef vector<int32_t> Vecd;

int32_t build_preorder(Vecd& inorder, Vecd& postorder, Vecd& preorder,
                       int32_t inorder_s, int32_t inorder_e, int32_t postorder_e) {
    if (inorder_s > inorder_e) {
        return 0;
    }

    preorder.push_back(postorder[postorder_e]);
    
    int32_t root = -1;
    for (int32_t i = inorder_s; i <= inorder_e; i++) {
        if (postorder[postorder_e] == inorder[i]) {
            root = i;
            break;
        }
    }

    build_preorder(inorder, postorder, preorder, inorder_s, root - 1, postorder_e - (inorder_e - root) - 1);
    build_preorder(inorder, postorder, preorder, root + 1, inorder_e, postorder_e - 1);

    return 0;
}

int32_t solution(Vecd& inorder, Vecd& postorder) {
    Vecd preorder;
    build_preorder(inorder, postorder, preorder, 0, inorder.size() - 1, postorder.size() - 1);
    for (int32_t i = 0; i < preorder.size(); i++) {
        cout << preorder[i] << ' ';
    }
    cout << '\n';
    return 0;
}

int main(void) {
    int32_t n;
    cin >> n;
    Vecd inorder(n);
    Vecd postorder(n);  
    for (int32_t i = 0; i < n; i++) {
        cin >> inorder[i];
    }
    for (int32_t i = 0; i < n; i++) {
        cin >> postorder[i];
    }
    solution(inorder, postorder);
    return 0;
}
```
