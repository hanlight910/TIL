# 💳 문제이해

N개의 도시(정점)가 주어집니다. 그리고 M개의 버스(간선)이 주어집니다.
간선은 u, v, w 형식으로 주어집니다. u는 출발하는 도시, v는 도착하는
도시, w은 정수입니다. 양수일수도, 음수일수도, 0일 수도 있습니다.

## 🚥 문제접근

가중치가 음수일 경우 `Dijkstra` 알고리즘을 사용 하면
오답을 낼 수 있습니다. 

양수와 음수 두 개다 사용할 수 있는 `Bellman-Fold`
알고리즘을 사용할 수 있습니다.

### 🌏 분석

#### ☔ Bellman-Fold 

가중치가 음수일 때도 최단 거리를 구할 수 있는 알고리즘입니다.

`dijkstra`알고리즘 같은 경우 음수가 포함될 경우 최단 거리가
바뀔 가능성이 있습니다. 이는 `heap`자료 구조를 사용하면서, 최소 가중치에서
간선을 우선적으로 다루는 `heap` 구조의 특성 때문입니다.

Bellman-Fold 알고리즘은 최소 가중치가 담긴 점정과 인접한
간선들만 탐색합니다.

하지만 `Bellman-Fold`는 모든 간선을 탐색합니다.

그래서 시간 복잡도 $O(V * E)$를 기록합니다.

### 🛠️ 풀이

#### 🖥️ source code

```cpp
#include<stdio.h>
#include<stdint.h>
#include<stdlib.h>

#define INF 0xFFFFFFFFF

struct Edge {
    int32_t src, dst, weight;
};

struct Graph {
    int32_t V;
	int32_t E;
	Edge* arr;
};

int32_t bellmand_fold(Graph* g, int32_t start) {
    int64_t* distance = (int64_t*)calloc(g->V, sizeof(int64_t));
    
    for (int32_t i = 0; i < g->V; i += 1) {
        *(distance + i) = INF;
    }
    distance[start] = 0;
    
    for (int32_t i = 1; i < (g->V - 1); i += 1) {
        for (int32_t j = 0; j < g->E; j += 1) {
            auto [src, dst, weight] = g->arr[j];
			if (distance[src] != INF && distance[src] + weight < distance[dst]) {
				distance[dst] = distance[src] + weight;
			}
        }
    }

	for (int32_t i = 0; i < g->E; i += 1) {
		auto [src, dst, weight] = g->arr[i];	
		if (distance[src] != INF && distance[src] + weight < distance[dst]) {
			printf("-1\n");
			return -1;
		}
	}

	for (int32_t i = 2; i < g->V; i += 1) {
		if (distance[i] == INF) printf("-1\n");
		else printf("%ld\n", distance[i]);
	}
	return 0;
}

int32_t main(void) {
    int32_t N, M;
    scanf("%d %d", &N, &M);
	Graph g = { .V = (N + 1), .E = M };
	g.arr = (Edge*)malloc(M * sizeof(Edge));
	for (int32_t i = 0; i < M; i += 1) {
		scanf("%d %d %d", &(*(g.arr + i)).src, &g.arr[i].dst, &g.arr[i].weight);
	}
	bellmand_fold(&g, 1);
	// printf("%x\n", -10000 * 6000);

    return 0;
}
```
