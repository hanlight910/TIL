# 💳 문제이해

N개의 물건의 무게가 주어집니다. 가방의 최대 넣을 수 있는 무게 C가 주어집니다.
N개의 물건을 넣을 수 있는 방법으로 수를 구하시오.

- C와 각 물건의 무게들은 10^9이하의 자연수입니다.

## 🚥 문제접근

- N: 2
- C: 1
- 물건의 무게: 
    - 1, 1

위 예시처럼 입력값이 주어졌을 때 N개의 물건을 넣을 수 있는 수는
3개입니다.

3개 인 이유는 아무래도 넣지 않는 물건 개수 0을 고려하는 것 같습니다.

**물건을 넣는 방법들:**

1. 첫 번째 물건
2. 두 번째 물건
3. 물건을 넣지 않음

`Brute force`로 완전탐색을 하면 구할 수 있을 것 같습니다. 

해당 수열은 연속된 합을 구하는 게 아닙니다. 따지자면 부분합을 구해 
가방의 담을 수 있는 최대 무게만 맞추면 됩니다.

### 🌏 분석

- 예시:
- 1, 5, 1, 1, 3, 2
- 가방의 최대 무게: 3

- 주어진 물건의 무게들을 과연 정렬을 해야 할까요?
- 1, 1, 1, 2, 3, 5

- 정렬을 해놓으면 첫 번째 원소부터 두 개의 원소를 추적을 하면서 부분 합을
구할 수 있습니다.
    - 그리고 주의해야 할 것은 각 물건은 서로 다른 객체입니다. 주어진 수열은
    물건의 무게의 나타냅니다. 물건의 고유의 번호가 아닙니다. 그러니 무게가 
    같다고 서로 같은 물건이 아닌 것을 유의해야 합니다.

    - 요약하자면 중복이 허용됩니다. 즉 조합(combination)을 사용해야 합니다.
    하지만 조합 공식을 최악의 경우 `N`개 수행해야 합니다.
    이 또한 효율적인 방법은 아닙니다.

부분 집합의 합을 구하는 알고리즘은 $O(2^n)$가 걸립니다. 이 부분에서
`C`값 이하 만큼의 해당 되는 합의 개수를 구하면 됩니다.

다만 N이 클수록 지수적으로 느려집니다. N이 최대 30이라면, 해당 알고리즘으로는
수행 못할 가능성이 높습니다. 더 단축시켜야 합니다.

##### 🖥️ source code

```cpp
#include<algorithm>
#include<stdint.h>
#include<iostream>
#include<vector>

std::vector<int64_t> get_sum_power_set(std::vector<int64_t> v) {
	std::vector<int64_t>sum_power_set;
	for (int32_t i = 0; i < (1 << v.size()); i += 1) {
		int64_t sum = 0;

		for (int32_t j = 0; j < v.size(); j += 1) {
			if (i & (1 << j)) {
				sum += v[j];
			}
		}
		sum_power_set.push_back(sum);
	}

	return sum_power_set;
}

int32_t solution(std::vector<int64_t> v, int64_t u) {
	int32_t count = 0;

	std::vector<int64_t> left_sum_power_set(v.begin(), v.begin() + v.size() / 2);
	std::vector<int64_t> right_sum_power_set(v.begin() + v.size() / 2, v.end());

	left_sum_power_set = get_sum_power_set(left_sum_power_set);
	right_sum_power_set = get_sum_power_set(right_sum_power_set);

	std::sort(right_sum_power_set.begin(), right_sum_power_set.end());

	for (auto& sum: left_sum_power_set) {
		if (sum <= u) {
			count += std::upper_bound(
					right_sum_power_set.begin(), 
					right_sum_power_set.end(),
					u - sum
					) - right_sum_power_set.begin();
		}
	}

	return count;
}

int32_t main(void) {
	int N, C;
	std::cin >> N;
	std::cin >> C;
	std::vector<int64_t> v(N);

	for (int32_t i = 0; i < N; i += 1) {
		std::cin >> v[i];
	}
	int32_t count = solution(v, C);
	std::cout << count;
	
	return 0;
}
```
