# 💳 문제이해

이진 검색 트리가 주어집니다. 전위 순회의 과정이 주어지면, 후위 순회의
과정을 구하시오. 

**이진 검색 트리의 구조**:
- 왼쪽 자식 부분 나무: 왼쪽에 있는 모든 노드들은 부모 노드보다 작아야 합니다.
- 오른쪽 자식 부분 나무: 오른쪽에 있는 모든 노드들은 부모 노드보다 커야 합니다.

# 🚥 문제접근

원래는 전위 과정을만을 통해 후외 과정을 구할 수 없습니다.

가령
- 50, 30, 24, 45, 5, 28, 98, 52, 60

의 전위 과정이 주어집니다. 루트는 쉽게 구할 수 있습니다. 
전위 순회 특성상 첫 번째 노드가 루트 노드입니다. 
하지만 왼쪽, 오른쪽 부분 나무를 정확하게 구할 수 없습니다.
30부터 어딕까지가 왼쪽 부분 트리인지 구분이 안 됩니다.

하지만 이분 탐색 트리 특성을 이용하면 정확한 트리를 구할 수 있습니다.

## 🌏 분석

1. 50은 루트입니다. 그렇다면 나머지 노드들은 왼쪽 오른쪽 부분 트리입니다.
2. 왼쪽 오른쪽 부분 트리를 구합니다. 30은 루트보다 작으므로 왼쪽 노드입니다.
3. 24는 30보다 작으므로 30의 왼쪽 노드입니다.
4. 45는 50보다 작고 30보다 크므로 30의 오른쪽 노드입니다.
5. 5는 24보다 작고 30보다 작으므로 24의 왼쪽 노드입니다.
6. 28은 24보다 크고 30보다 크기 때문에 24의 오른쪽 노드입니다.
8. 98은 30보다 크고 루트인 50보다 크기 때문에 루트의 오른쪽 노드입니다.
9. 52는 30보다 크고 98보다 작기 때문에 98의 왼쪽 노드입니다.
10. 60은 98보다 작고 52보다 크기 때문에 52의 오른쪽 노드입니다.

그러면 어떻게 해야 왼쪽, 오른쪽 부분 나무를 나눌 수 있을까요?
`Binary Search Tree`의 특성을 떠올립니다.

> "왼쪽 부분 나무의 노드들은 루트보다 작다. 반면 오른쪽 부분 나무의 노드들은
> 루트보다 크다."

왼쪽 부분 나무는 루트 다음이기 때문에, 바로 찾을 수 있습니다. 오른쪽
부분 나무는 루트를 기준으로 루트보다 큰 노드를 처음에 찾은 노드가 오른쪽
부분 나무의 루트입니다.

그 뒤에 재귀를 사용하여 아래 방법을 사용합니다.
1. 왼쪽 부분 나무의 구합니다.
2. 오른쪽 부분 나무를 구합니다.
3. 왼쪽 부분 나무를 위 과정을 거칩니다.
4. 오른쪽 부분 나무를 위 과정을 거칩니다.
4. 루트를 구합니다.

위 과정을 부분 나무의 트리가 더이상 탐색할 게 없을 때까지 찾습니다.

## 🛠️ 풀이

### 🖥️ source code

```cpp
#include<iostream>

#include<vector>

using namespace std;

typedef vector<int32_t> Vecd;

int32_t postorder(Vecd& preorder, int32_t preorder_s, int32_t preorder_e) {
    if (preorder_s > preorder_e) {
        return 0;
    }
    int32_t root = preorder_s;
    int32_t left_sub_tree = root + 1;
    int32_t right_sub_tree = root + 1;
    while (right_sub_tree <= preorder_e && preorder[right_sub_tree] < preorder[root]) {
        right_sub_tree += 1;
    }
    
	/*cout << root << left_sub_tree << right_sub_tree << '\n';*/
    postorder(preorder, left_sub_tree, right_sub_tree - 1);
    postorder(preorder, right_sub_tree, preorder_e);
    cout << preorder[root] << '\n';

	return 0;
}
int32_t main(void) {
    Vecd preorder;
    int32_t input;
    while (cin >> input) {
        preorder.push_back(input);
    }
    postorder(preorder, 0, preorder.size() - 1);

    return 0;
}

```
