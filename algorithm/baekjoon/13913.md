# 💳 문제이해

수빈이는 동생과 숨바꼭질을 하고 있습니다. 수빈이와 동생의 위치를 나타내는
자연수가 주어집니다. 수빈이는 자신의 위치 `x`에서 x - 1, x + 1, x * 2로 이동할
수 있습니다. 해당 연산들을 통해 최소한의 연산만 사용하여 동생을 찾으려고
합니다.

- 최소 연산 횟수
- 연산 과정

## 🚥 문제접근

수빈이의 위치와 동생의 위치는 0 이상, 100,000 이하의 자연수입니다. 최악의 경우
100,000 * 100,000 = 10,000,000,000 정도 소요될 수 있습니다. 제한 시간이
2초이므로 시간이 많이 걸릴 것으로 예상됩니다. $O(n * m)$을 피하고 더 효율적인
알고리즘을 생각해야 합니다.

이전에 풀었던 숨바꼭질 문제를 해결할 때, 시간 복잡도는 $O(V + E)$였습니다.
`BFS`를 통해 풀었습니다. 수빈이의 이동할 수 있는 경우의 수는 3가지입니다.

### 🌏 분석 

**예시**:

- 수빈이의 위치: 5
- 동생이의 위치: 17

1. 수빈이의 현재 위치: 5
    1. 수빈이의 현재 위치: 5 - 1 = 4
    2. 수빈이의 현재 위치: 5 + 1 = 6
    3. 수빈이의 현재 위치: 5 * 2 = 10
        1. 수빈이의 현재 위치: 4 - 1 = 3
        2. 수빈이의 현재 위치: 4 + 1 = 5 // 이미 방문했으므로 스킵
        3. 수빈이의 현재 위치: 4 * 2 = 8
        4. 수빈이의 현재 위치: 6 - 1 = 5 // 스킵
        5. 수빈이의 현재 위치: 6 + 1 = 7 
        6. 수빈이의 현재 위치: 6 * 2 = 12

기타...

위 방식은 너비를 우선적으로 탐색하는 `BFS` 방식입니다. 해당 방식이 가장
효율적인지는 모르겠습니다.

#### 🛠️ 풀이


##### `BFS`(너비 우선 탐색)

`BFS`를 통해 최단 거리를 구합니다. 각 원소에 최단 거리를 구하는 과정에서, 각
원소의 값에 이전 원소를 저장하는 배열을 저장합니다. 이는 나중에 목표 원소를
기준으로 이전 원소, 그 이전 원소, 그 이전 이전 원소를 탐색하기 위함입니다.

###### 백트래킹

- 백트래킹\[현재원소] = 이전 원소

현재 원소의 이전 원소를 저장하는 이유는 `BFS` 특성상 처음으로 방문한 원소가
시작 원소의 시작한 가장 빠르게 갈 수 있는 경로이기 때문에, 그냥 이전 원소를
저장하는 겁니다.

**예시**:
- 수빈이의 위치: 5
- 동생의 위치: 17
- 최단 경로: 5 -> 4 -> 8 -> 16 -> 17
- 백트래킹: 17 -> 16 -> 8 -> 4 -> 5

## 🎑 후기

숨바꼭질 문제는 이전에도 여러번 풀어서 방법을 떠올리는 건 어렵지 않았습니다.
다만 `BFS`방법이 최선인지는 모르겠습니다.

#### 🖥️ 소스 코드

```cpp
#include<iostream>
#include<vector>
#include<queue>

#define DIRECTIONS { 1, 1, 2 }

enum OPERATION { ADD, MINUS, MULTIPLICATION };

using namespace std;

typedef vector<int32_t> VecD;

struct Capacity {
	int32_t max;
	int32_t min;
};

int32_t operate(OPERATION op, int32_t cur_pos) {
	switch (op) {
		case(ADD):
			return cur_pos + 1;
		case(MINUS):
			return cur_pos - 1;
		case(MULTIPLICATION):
			return cur_pos * 2;
	}

	return -1;
}

bool is_valid(int32_t cur_pos, Capacity &c) {
	if (c.min <= cur_pos && cur_pos <= c.max) {
		return 1;
	}
	return 0;
}

VecD bfs(int32_t N, int32_t W) {
	int32_t max_boundary = max(N, W);
    VecD visited(max_boundary + 2, 0);
	VecD count(max_boundary + 2, 0);
	VecD tracking(max_boundary + 2, -1);

	Capacity c = { 
		.max = max_boundary + 1,
		.min = 0,
	};

	VecD directions = DIRECTIONS;
	queue<int32_t> q;
	q.push(N);
	count[N] = 0;
	visited[N] = 1;

	while (!q.empty()) {
		int32_t cur_pos = q.front();
		q.pop();

		for (int32_t i = 0; i < 3; i += 1) {
			int32_t next_pos = operate(OPERATION(i), cur_pos);
			
			if (is_valid(next_pos, c) && visited[next_pos] == 0) {
				/*cout << next_pos << '\n';*/
				count[next_pos] = count[cur_pos] + 1;
				visited[next_pos] = 1;
				q.push(next_pos);
				tracking[next_pos] = cur_pos;
			}
		}
	}

	cout << count[W] << '\n';

	return tracking;
}

int32_t backtracking(int32_t target, VecD tracked) {
	VecD result;
	int32_t idx = target;
	result.push_back(target);
	while (idx != -1 && tracked[idx] != -1) {
		result.push_back(tracked[idx]);
		idx = tracked[idx];
	}

	for (int32_t i = 0; i < result.size() / 2; i += 1) {
		int32_t temp = result[result.size() - 1 - i];
		result[result.size() - 1 - i] = result[i];
		result[i] = temp;
	}
	for (auto& el: result) {
		cout << el << ' ';
	}
	cout << '\n';
	return 0;
}

int32_t solution(int32_t N, int32_t W) {
	VecD tracked = bfs(N, W);
	backtracking(W, tracked);

	return 0;
}
int32_t main(void) {
    int32_t N, W;
    cin >> N >> W;
	solution(N, W);
    return 0;
}
```
