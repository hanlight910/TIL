# 💳 문제이해

N의 정수가 주어졌을 때 연속된 소수의 합으로 구할 수 있는 경우의 수를 
구하시오.

## 🚥 문제접근

자연수가 주어졌을 때:

- 3: 한가지
    - 3
- 41: 3가지
    - 2 + 3 + 5 + 7 + 11 + 13 = 11 + 13 + 17 = 41 

자연수 N까지 범위의 소수를 구해야 할 것 같습니다.

투 포인터로 방식으로 양 쪽 끝에 있는 두 수를 추적합니다.
한쪽은 가장 작은, 한 쪽은 가장 큰.

### 🌏 분석

소수를 N까지 구합니다.

각 끝에 있는 

#### ⚒️  풀이

1. 소수를 2부터 N까지 구합니다.
    - 모든 소순s
2. 각 끝에 있는 작은 수와, 큰 수로 가지고 탐색 범위를 좁힙니다.

##### 🖥️ sourc code 

```cpp

#include<iostream>
#include<stdint.h>
#include<vector>

int32_t is_prime(int32_t num) {
    if (num <= 1) return false;
    if (num <= 3) return true;
    if (num % 2 == 0) return false;
    if (num % 3 == 0) return false;

    for (int32_t i = 5; (int64_t)i * i <= num; i += 6) {
        if (num % i == 0 || num % (i + 2) == 0) {
            return false;
        }
    }
    return true
}

int32_t solution(int32_t N) {
    std::vector<int32_t> v;
    v.push_back(2);
    for (int32_t i = 3; i <= N; i += 2) {
        if (is_prime(i)) {
            v.push_back(i);
        }
    }
	// printf("prime numbers: %ld\n", v.size());

    int32_t start = 0;
    int32_t end = -1;
    int32_t current_sum = 0;
    int32_t count = 0;
    int32_t length = v.size();

    while (end <= length) {
        if (current_sum >= N) {
            if (current_sum == N) count += 1;
            current_sum -= v[start];
            start += 1;
        } else if (end < length) {
            end += 1;
            current_sum += v[end];
        } else {
            break;
        }
	}
    return count;
}

int32_t main(void) {
    int32_t N; 
    std::cin >> N;
    int32_t cnt = solution(N);
	std::cout << cnt << '\n';
    return 0;
}
```
