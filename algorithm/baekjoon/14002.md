# 💳 문제이해

양의 정수로 구성되어 있는 수열이 주어집니다. 가장 긴 부분 수열의 길이와
그 원소들을 구하시오.

## 🚥 문제접근

동적 계획법을 통해 구할 수 있을 것 같습니다.

### 🌏 분석

동적 계획버을 통해 각 원소의 가장 긴 부분 수열의 길이를 저장합니다. 그 뒤에
각 원소를 탐색할 때마다 이전 원소에서 자기보다 작은 부분 수열을 
찾습니다.

- 10 20 10 30 20 50

1. 원소 10에 방문합니다.
    - 이전 원소가 없으므로 탐색하지 않습니다.
    - 원소 10의 가장 긴 부분 수열은 10 본인입니다.
2. 원소 20에 방문합니다.
    - 이전 원소에 20보다 작은 10이 있습니다. 
    - 10이 가장 긴 부분 수열 길이를 가졌습니다.
    - 20의 가장 긴 부분 수열의 길이는 1 + 1 = 2 입니다.
3. 원소 10에 방문합니다.
    - 이전 원소들을 탐색해본 10보다 작은 원소는 없습니다.
    - 따라서 10의 가장 긴 부분 수열의 길이는 1입니다.
4. 원소 30의 방문합니다.

... 해서 마지막 원소인 50까지, 위 규칙을 적용합니다.

해당 방법은 최악의 경우 시간복잡도 $O(n^2)$를 기록합니다.

다만 더 빠른 방법이 있다고 합니다.

위 방법은 현재 원소 이전에 원소중에서 자기보다 작으면서 가장 긴 부분 수열의
길이를 가진 원소를 찾을 때 $O(n)$ 번 걸립니다. 이 때문에 모든 원소를 순회할 때,
$n^2$이 걸립니다. 

그러니 현재 원소 이전에 원소 중에서 자기보다 작으면서 가장 긴 부분 수열의 길이를
찾는 알고리즘/방법에서 시간을 줄여야합니다. 

- 최장 길이 = 가장 긴 부분 수열의 길이

- 10, 20, 10, 30, 20, 50 각 원소의 최장 길이는
- 1,  2,  1,  3,  2,  4 입니다.

위 부분에서 이전 원소들을 전부 탐색하는 방법 외에 떠오르지 않습니다.
대표적인 탐색 방법 중,
이분 탐색을 사용하고 싶어도, 정렬이 되어 있는 수열이 없습니다.

그러나 방법은 있습니다.

#### 🚮 Binary Search

가장 긴 수열을 실시간으로 추적하면 됩니다.
`Longest Increasing Subsequence`(LIS)

**규칙**:
- 현재 원소가 마지막 원소보다 크면, 마지막 다음으로 추가합니다.
- 작으면, 현재 원소보다 크거나 같으면서 가장 작은 원소랑 교체합니다.

1. 10을 방문했습니다. LIS 배열이 비어 있습니다. 10을 추가합니다.
2. 20을 방문했습니다. LIS 배열의 마지막 원소인 10보다 큽니다. 고로 추가합니다.
3. 10을 방문해습니다. 
    - LIS 배열의 마지막 원소인 20보다 작습니다.
    - 이분 탐색으로 10보다 크거나 같은 가장 작은 원소인 10과 교체합니다.
4. 30을 방문했습니다. 
    - LIS 배열의 마지막 원소인 20보다 큽니다.
    - 30을 추가합니다.
    - 현재 `LIS`: 10, 20, 30
5. 20을 방문합니다.
    - `LIS` 배열의 마지막 원소인 30보다 작습니다.
    - 이분 탐색으로 20보다 크거나 같으면서 가장 작은 원소인 20이랑 교체합니다.
    - 현재 `LIS`: 10, 20, 30
6. 50을 방문합니다.
    - `LIS` 배열의 마지막 원소인 30보다 큽니다.
    - 50을 추가합니다.
    - 현재 `LIS`: 10, 20, 30, 50

이처럼 `LIS`의 길이는 이분 탐색으로 보장할 수 있습니다.
하지만 `LIS`의 원소들을 보장 못할 수도 있습니다.

예를 들어 위 예시에서, 원소 1이 마지막 원소일 경우
1 보다 크면서 같은 원소이면서 가장 작은 원소는 10이랑
교체합니다. 결과적으로 `LIS`의 구조는: 1, 20, 30, 50 이렇게 됩니다.
정답은 10, 20, 30, 50 이지만 말입니다.

#### 원소 구하기

LIS의 원소들을 구하기 위해서는 개별로 처리를 해주어야 합니다.
`LIS`를 구하기 위해서는 탐색할 때마다, 해당 원소의 위치/인덱스를 저장합니다.

- 여기서 가장 긴 이덱스를 가진 원소가 `LIS`의 마지막 원소를 의미합니다.
- `LIS`의 저장된 50의 인덱스는 4입니다. 

이유는 `LIS`구조가 10, 20, 30, 50 이기 때문입니다.

가장 큰 인덱스를 하나식 줄이면서 내림차순으로 구합니다.

##### 🖥️ source code

```cpp
#include <iostream>
#include <algorithm>
#include <stdint.h>
#include <vector>

using namespace std;

template<typename T>
int32_t solution(const T& v) {
    int32_t n = v.size();    

    vector<int32_t> LIS;
    vector<int32_t> dp(n, 1);  

    LIS.push_back(v[0]);
    dp[0] = 1;  

    for (int32_t i = 1; i < n; i++) {
        auto pos = lower_bound(LIS.begin(), LIS.end(), v[i]) - LIS.begin();

        if (pos == LIS.size()) {
            LIS.push_back(v[i]);
        } else {
            LIS[pos] = v[i];
        }
        dp[i] = pos + 1;
    }


    int32_t max_length = *max_element(dp.begin(), dp.end());  

	cout << max_length << '\n';
	
	vector<int32_t> result;
	for (int32_t i = n - 1; i >= 0; i -= 1) {
		if (dp[i] == max_length) {
			result.push_back(v[i]);
			max_length -= 1;
		}	
	}

	for (int32_t i = 0; i < result.size() / 2; i += 1) {
		int32_t temp = result[result.size() - 1 - i];
		result[result.size() - 1 - i] = result[i];
		result[i] = temp;


		// for (int32_t i = 0; i < result.size(); i += 1) {
		// 	cout << result[i] << " ";
		// }
		//
		// cout << '\n';
	}

	for (int32_t i = 0; i < result.size(); i += 1) {
		cout << result[i] << " ";
	}
	cout << '\n';
	
	return 0;
}

int32_t main() {
    int32_t n;
    cin >> n;

    vector<int32_t> v(n);
    for (int32_t i = 0; i < n; i++) {
        cin >> v[i];
    }
    
    int32_t length_of_lis = solution(v);

    return 0;
}
```
