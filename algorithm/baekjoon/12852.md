# 💳 문제이해

정수 X가 주어집니다. 다음 3가지 연산이 가능합니다.

1. X가 3으로 나누어 떨어지면, 3을 나눕니다.
2. X가 2로 나누어 떨어지면, 2로 나눕니다.
3. X에서 1을 뺍니다.

1을 구하기 위해 필요한 연산 과정에서 최소 연산 횟수를 구하시오.
그리고 최소 연산 횟수의 과정 또한 구하시오.

## 🚥 문제접근

가중치가 서로 동일하고 최단 거리를 구할 수 있는 효율적인 알고리즘 중 하나인
`BFS`가 떠오릅니다. `DFS`을 통해 백트랙킹이 가능하지만, 최단 경로를
찾을려면 모든 경우의 수를 찾아야 할 수도 있습니다. 그러니 `BFS`를 사용합니다.

### 🌏 분석

하지만 `BFS`로 실행해 본 결과 시간 초과가 납니다. 이는
`BFS`가 최악의 경우 시간복잡도 $O(V + E)$를 넘으면 안된다는 것을 
의미합니다. 제한 시간은 **0.5**초로, V의 값은 최대 10^6, E의
값은 최대 3 * V개입니다. 그렇다면 더 효율적인 방법을 찾아야 합니다.
찾아본 결과 동적 프로그래밍으로 찾을 수 있다는 것을 알았습니다.

N의 연산 결과는 N이하의 수입니다. 이는 `2 ~ N` 까지의 범위를
갖습니다. 목표인 1에 도달하기 위해 필요한 경로 또한 `2 ~ N`입니다.

#### 🌂 Breadth-First search

`BFS`는 너비를 우선적으로 탐색합니다. 이는 먼저 도착한 노드/정점이 
곧 시작점에서 갈 수 있는 최단 거리임을 의미합니다.

시작 노드, X에서 파생될 수 있는 수들을 찾습니다. X / 3, x / 2, x + 1 
세가지 있습니다. 이제 각 루트를 동시적으로 탐색합니다. 탐색이 끝나면,
다음 깊이로 향합니다. 

하지만 이 방법은 시간 초과가 납니다.

#### 🪔 Dynamic Programming

동적 프로그래밍을 통해, 일정한 구간에서 목표까지 도달하는 알고리즘을
구현하는 것은 어렵지 않습니다. 

- `0 ~ N`까지 최소 횟수를 저장합니다.
    - 연산하기 이전 최소 횟수를 더합니다.
    - 각 연산 이전에 원소의서 최소값을 저장합니다.
    - 이를 `N`까지 반복합니다.

최소 횟수는 이렇게 구하고, 최단 경로를 추적하기 위해 최소 횟수의
원소만 저장합니다.

- 해당 원소가 이전 원소들과 비교하여 최소 횟수일 경우 해당 인덱 혹은 원소를
저장합니다.

**예시**:
- 1은 포함하지 않습니다.
- 최소 횟수는 초기의 최대 값으로 할당합니다.
- 1은 0으로 배정합니다.

1. 현재 원소: 2
    - 이전 결과로 2로 만들어진 경우의 횟수들을 찾습니다.
    1. 최소횟수 배열 2 / 2 = 1: 0
    2. 최소횟수 배열 2 / 3 = x  # 3의 배수가 아닙니다.
    3. 최소 횟수 배열 2 - 1 = 1: 0
    - 따라서 2의 최소 횟수는 0 + 1 = 1입니다.
    - 경로를 구하기 위해 최소 횟수의 인덱스를 저장합니다.
    - 2의 이전 최소 인덱스는 1 혹은 2입니다.
2. 현재 원소: 3
    - 이전 결과: 횟수들
    1. 최소횟수 배열 3 / 2  x // 2로 나누어 떨어지지 않음
    2. 최소 횟수 배열 3 / 3 = 1: 0
    3. 최소 횟수 배열 3 - 1 = 2: 1
    - 따라서 3의 최소 횟수는 0 + 1 = 1입니다.
    - 경로를 구하기 위해 최소 횟수의 인덱스를 저장합니다.
    - 3의 이전 최소 인덱스는 3입니다.

... 이를 N까지 반복합니다.

### 🛠️ 풀이

##### 🖥️ source code

```cpp
#include<iostream>
#include<stdint.h>
#include<vector>
#include<queue>

using namespace std;
int32_t get_min_v(int32_t N) {
    vector<int32_t> prefix_min_cnt(N + 1, 0x7FFFFFFF);
    vector<int32_t> tracking(N + 1, -1);
    
    min_cnt[1] = 0;

    for (int32_t i = 2; i <= N; i += 1) {
        int32_t min_cnt = 0x7FFFFFFF;

        if (i % 2 == 0 && prefix_min_cnt[i / 2] < min_cnt) {
            min_cnt = prefix_min_cnt[i / 2] + 1;
            tracking[i] = i / 2;
        }

        if (i % 3 == 0 && prefix_min_cnt[i / 3] < min_cnt) {
            min_cnt = prefix_min_cnt[i / 3] + 1;
            tracking[i] = i / 3;
        }

        if (prefix_min_cnt[i - 1] < min_cnt) {
            min_cnt = prefix_min_cnt[i - 1] + 1;
            tracking[i] = i - 1;
        }

        prefix_min_cnt[i] = min_cnt; 
    }

    cout << prefix_min_cnt[N] << '\n';

    cout << N << ' ';
    for (int32_t i = N; i >= 1;) {
        cout << tracking[i] << ' ';
        i = tracking[i];
    }

    return 0;
}

int32_t solution(int32_t N) {
    get_min_v(N);
    return 0;
}

int32_t main(void) {
    int32_t N;
    std::cin >> N;
    solution(N);
    return 0;
}
```
