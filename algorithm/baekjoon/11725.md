# 💳 문제이해

루트가 없는 트리가 주어집니다. 정점 1을 루트라고 합니다. 정점은 두 개의 인접한
노드가 주어집니다. 2부터 시작하여 순서대로 각 노드의 부모 노드를 구하시오.

# 🚥 문제접근

## ❌ 실패

> "해당 접근은 실패하였습니다."

부모 노드라고는 하지만 제일 먼저 인접한 노드를 부모 노드라고 취급하는
것 같습니다. 

트리 탐색 알고리즘까지는 필요 없고, 배열 인덱싱을 통해 부모 노드를 구할 
수 있을 것 같습니다.

### 🌏 풀이

> "해당 풀이는 실패하였습니다."

**부모 노드가 되기 위한 조건**:
1. 인접한 노드
2. 처음으로 인접한 노드
3. 두 개의 노드가 주어졌을 때, 두 노드는 서로가 부모 노드다.

**인덱싱**:
1. 노드 번호는 2 이상의, 100,000 이하의 정수입니다. 인덱싱을 통해,
부모 노드를 저장합니다.
2. 처음으로 인접한 노드가 부모 노드이므로, 이미 이미 인접한 노드가 있으면
스킵합니다.

간선이 한개를 구하므로 트리 구조가 필요 없습니다. 부모 노드가 아닌
다른 노드 사이의 관계성이 있지 않다고 판단되기 때문에, 단순 인덱싱으로 
처리합니다.


#### 🛠️ 풀이

##### 🖥️ source code

```cpp
#include<iostream>
#include<vector>

using namespace std;
typedef vector<int32_t> VecD;

int32_t main(void) {
    int32_t N;
    cin >> N;

    VecD unary_adjacent_list(N, -1);

    for (int32_t i = 0; i < N; i += 1) {
        int32_t src1, src2;
        cin >> src1 >> src2;
        if (unary_adjacent_list[src1] == -1) {
            unary_adjacent_list[src1] = src2;
        } 
        if (unary_adjacent_list[src2] == -1) {
            unary_adjacent_list[src2] = src1;
        }
    }

    for (int32_t i = 2; i <= N; i += 1) {
        cout << unary_adjacent_list[i] << '\n';
    }
    return 0;
}
```

## 🚡 두 번째

부모 노드의 기준이 처음으로 인접한 노드가 절대적인 기준이 아니었습니다.
정점 노드가 1이라는 가정하면, 자연스럽게 1의 인접한 정점들이 두 번째
루트, 두 번째로 높은 부모 노드라는 것을 시사합니다.

이렇게 되면 트리를 그리는게 맞습니다. 트리 탐색 알고리즘 중 `BFS`와 `DFS`를
사용하면 될 것 같습니다.

### 🌏 분석

`DFS`를 통해 부모 정점의 인접한 정점들의 부모 노드의 번호를
저장하면서, 인접한 노드들을 깊이 우선으로 탐색합니다.

1. 부모 노드의 인접한 노드들을 찾는다.
2. 인접한 노드들의 부모 노드의 번호를 저장한다.
3. 인접한 노드에 위 과정을 반복한다.
4. 더 이상 노드가 없으면, 현재 노드의 부모 노드의 다른 인접한 노드를
탐색한다.
5. 3, 4번을 반복한다. 

#### 🛠️ 풀이

##### 🖥️ source code

```cpp
#include<iostream>
#include<vector>

using namespace std;
typedef vector<vector<int32_t>> Graph;

int32_t DFS(Graph& g, vector<int32_t>& visited, int32_t& parent_n, vector<int32_t>& result) {
    for (int32_t i = 0; i < g[parent_n].size(); i += 1) {
        int32_t adj_n = g[parent_n][i];
        if (visited[adj_n] == 0) {
            visited[adj_n] = 1;
            result[adj_n] = prent_n;
            DFS(g, visited, adj_n, result);
        }
    }
    return 0;
}
int32_t main(void) {
    int32_t N;
    cin >> N;
    Graph adj_l(N + 1);
    vector<int32_t> visited(N + 1, 0);
    vector<int32_t> result(N + 1, -1);
    for (int32_t i = 0; i < N; i += 1) {
        int32_t src1, src2;
        cin >> src1 >> src2;
        adj_l[src1].push_back(src2);
        adj_l[src2].push_back(src1);
    }

    DFS(g, visited, 1, result);
    
    for (int32_t& pn: result) {
        cout << pn << '\n';
    }
    return 0;
}

```
