# 💳 문제이해

1 이상 1,000,000,000 이하의 종류의 용액과, -1 이하 -1,000,000,000 이상의
종류의 용액이 주어집니다. 용액이 N개 주어졌을 때, 두 용액의 특성을
합한 경우 0에 가까운 두 용액의 특성을 구하시오.

## 🚥 문제접근

N이 100,000입니다. 시간 복잡도 $O(n^2)$로는 시간 초과가날 것입니다.

마이너스끼리 더하면 값은 더 작아집니다. 양수끼리 더하면 값은 더 커집니다.
적절한 균형을 찾아야합니다.

### 🌏 분석

1. 우선 정렬을 통해 작은 수와 큰 수의 구간을 나눕니다.
2. 양쪽 끝에 있는 가장 작은 수와 큰 수를 더합니다.
3. 해당 더한 값이 0과의 차이가 이전 더한 값보다 차이가 적을 경우 
0에 가장 근접한 값을 업데이트합니다.
4. 현재 더한 값이 0이라면 더한 두 수를 반환합니다.
    - 만약에 더한 값이 0보다 크면 더 작은 수를 더합니다.
    - 만약에 더한 값이 0보다 작으면 더 큰 수를 더합니다.

##### 🖥️ source code

```cpp
#include <algorithm>
#include<stdio.h>
#include<stdint.h>
#include<stdlib.h>
#include<vector>

struct pair {
    int64_t small;
    int64_t big;
    pair(int32_t s, int32_t b) { small = s; big = b;  };
};

pair solution(int32_t N, std::vector<int64_t> v) {
    int32_t i = 0; 
    int32_t j = N - 1;
	int32_t big = v[j], small = v[i];

	int64_t prev_closest_zero = 0x7FFFFFFFFFFFFFFF;
	int64_t current_closest_zero = big + small;
    while (i < j) {
		// printf("i: %d; j: %d\n", i, j);
		current_closest_zero = v[i] + v[j];
	
		if (abs(current_closest_zero) < abs(prev_closest_zero)) {
			prev_closest_zero = current_closest_zero;
			big = v[j];
			small = v[i];
		}

		if (current_closest_zero == 0) {
			return pair(small, big);
		} else if (current_closest_zero < 0) {
			i += 1;
		} else {
			j -= 1;
		}
    }
    return pair(small, big);
}
int32_t main(void) {
    int32_t N;
	scanf("%d", &N);
    std::vector<int64_t> v(N);
    for (int32_t i = 0; i < N; i += 1) {
        scanf("%ld", &v[i]);
    }
	std::sort(v.begin(), v.end());
    auto [a, b] = solution(N, v);
	printf("%ld %ld\n",  a, b);

    return 0;
}
```
