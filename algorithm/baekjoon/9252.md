# 💳 문제이해

두 개의 수열이 주어집니다. 가장 긴 공통 수열을 구하시오.
`Longest Common Subsequence`.


## 🚥 문제접근

두 개 이상의 대상을 비교할 때 행열/메트릭스 구조를 씁니다.

### 🌏 분석

`Dynamic Programming`을 통해 이전에 구한 가장 긴 공통 수열의 길이를 저장합니다.

| x / y | A | C | A | Y | K | P | A |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
|   C   | 0 | 1 | 1 | 1 | 1 | 1 | 1 |
|   A   | 1 | 1 | 2 | 2 | 2 | 2 | 2 |
|   P   | 1 | 1 | 2 | 2 | 2 | 3 | 3 |
|   C   | 1 | 2 | 2 | 2 | 2 | 3 | 3 |
|   A   | 1 | 2 | 3 | 3 | 3 | 3 | 4 |
|   K   | 1 | 2 | 3 | 3 | 4 | 4 | 4 | 


위 표와 같이 두 개의 수열의 인덱스 끝에서 가장 긴 공통 수열의 길이를
구할 수 있습니다.

- K, A = 4

공식은 아래와 같습니다.

- `LCS` = 가장 긴 공통 수열의 길이

$$ if\ 수열1[x] == 수열2[y] then\ add = 1;\ else\ add = 0 $$
$$ dp[x][y] = max(dp[y][x - 1] + add, dp[y - 1][x])$$

이제 주어진 `dp`로 `LIS`를 구합니다. 갱신 되는 부분을 역추적 하면 구할 수 있습니다.
역추적 할 때는 현재 원소 기준, \[y - 1]\[x - 1] 이하를 만족해야 합니다.

- 현재 x가 5이고 y가 4일 때, x는 5미만 y는 4미만에서 이전 원소들을 찾아야 
합니다.
- 찾는 조건은 새로 갱신되었거나, 두 수열의x, y의 원소가 서로 같아야 합니다.

#### 🖥️ source code
```cpp
#include<iostream>
#include<vector>
#include<cstdint>
#include<cstring>

typedef const char* String;
typedef vector<int32_t> VecD

int32_t solution(String a, String b) {
    int32_t len_a = strlen(a), len_b = strlen(b);
    VecD<VecD> dp(len_a + 1, VecD(len_b + 1, 0));

    for (int32_t i = 0; i <= len_a; i += 1) {
        for (int32_t j = 0; j <= len_b; j += 1) {
            if (i == 0 || j == 0) {
                dp[i][j] = 0;
            } else if (a[i - 1] == b[j - 1]) {
                dp[i][j] = dp[i][j - 1] + 1;
            } else {
                dp[i][j] = (dp[i - 1][j] > dp[i][j - 1] ? dp[i - 1][j] : dp[i][j - 1]);
            }
        }
    }
    
    int32_t longest_length = dp[len_a][len_b];
    cout << longest_length << '\n';

    while (len_a >= 0 || len_b >= 0) {
        if (a[len_a - 1] == a[len_b - 1]) {
            cout << a[len_a] << ' ';
            len_a -= 1;
            len_b -= 1;
        } else if (dp[len_a - 1][len_b] > dp[len_a][len_b - 1]) {
            len_a -= 1;
        } else {
            len_b -= 1;
        }
    }
}
int32_t main(void) {
    String a;
    String b;
    cin >> a;
    cin >> b;
    
    return 0;
}
``` 
