# 💳 문제이해

N개의 정수가 주어집니다. `LIS`(Longest Increasing Subsequence)를 구하시오.

## 🚥 문제접근

`LIS`를 `DP`와 이분 탐색을 사용합니다.

### 🌏 분석

`binary search`를 사용하는 편이 `dp`만을 사용하는 것보다 더 효율적입니다.

#### 💲 Dynamic Programming

**동적 계획법**은  작은 케이스들을 활용하여 더 큰 케이스를 효율적으로
해결하기 위한 방법입니다.

- 이분 탐색으로 찾은 `lower bound` 인덱스를 저장합니다.

#### 🚮 Binary-Search

정렬된 상태에 수열에서 탐색 범위를 절반식 줄이면서
찾는 $O(log_2 n)$ 걸리는 효율적인 탐색 알고리즘 중 하나입니다.

이분 탐색 알고리즘을 통해 실시간으로 `LIS`를 추적합니다.

`lower bound`: 찾는 원소보다 크거나 같은 원소 중에서 가장 작은 원소를
구합니다.

- 10, 20, 30, 40, 50

위 수열에서 20의 `lower bound`를 찾습니다.

1. mid = 0 + (4 - 0) / 2 = 2: 30
    - mid = 2
    - 30 >= 20 
    - right = mid - 1
2. mid = 0 + (1 - 0) / 2 = 0: 10  
    - mid = 0
    - 20 < 10
    - left = mid + 1
    - ans = mid
3. mid = 1 + (1 - 1) / 2 = 1: 10
    - 10 < 20
    - right = mid - 1
    - left > right
    - return ans

### 🛠️ 풀이

#### 🖥️ source code

```cpp
#include <algorithm>
#include<iostream>
#include<stdint.h>
#include<vector>

using namespace std;
typedef vector<int64_t> VecD;

int32_t lower_bound(VecD& v, int32_t value) {
    int32_t left = 0;
    int32_t right = v.size() - 1;
    int32_t ans = -1;

	if (v.empty()) {
		return 0;
	}

    while (left <= right) {
        int32_t mid = left + (right - left) / 2;  
        if (v[mid] >= value) {
            right = mid - 1;
        } else {
            ans = mid;
            left = mid + 1;
        }
    }
    return ans + 1;
}

int64_t get_max(VecD v) {
    int64_t max = v[0];

    for (int32_t i = 1; i < v.size(); i += 1) {
        if (max < v[i]) {
            max = v[i];
        }
    }
    return max;
}

int32_t solution(VecD v) {
    VecD lis;
    VecD dp(v.size(), -1);

    for (int32_t i = 0; i < v.size(); i += 1) {
        int32_t pos = lower_bound(lis, v[i]);
		/*int32_t pos = lower_bound(lis.begin(), lis.end(), v[i]) - lis.begin();*/

        if (pos == lis.size()) {
            lis.push_back(v[i]);
        } else {
            lis[pos] = v[i];
        }

        dp[i] = pos + 1;
    }

    VecD result;
    int64_t max_length = get_max(dp);

    for (int32_t i = dp.size() - 1; i >= 0; i -= 1) {
        if (max_length == dp[i]) {
            result.push_back(v[i]);
            max_length -= 1;
        }
    }

    for (int32_t i = 0; i < result.size() / 2; i += 1) {
        int64_t temp = result[result.size() - 1 - i];
        result[result.size() - 1 - i] = result[i];
        result[i] = temp;
    }
    
    cout << result.size() << '\n';

    for (auto& ele: result) {
        cout << ele << ' ';
    }
    cout << '\n';
	return 0;
}

int32_t main(void) {

    int32_t n;
    cin >> n;
    VecD v(n);

    for (int32_t i = 0; i < n; i += 1) {
        cin >> v[i];
    }

    solution(v);

    return 0;
}
```
